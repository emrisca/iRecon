# iRecon 0.4.0

This release adds project-trained detectors and crop classifiers, a usable
dataset export path, and a second interface pass.

## Detectors

- Import a project ONNX detector from the Detectors page.
- Import a stock RF-DETR export with `dets` and `labels` outputs.
- Import a YOLOv8 or YOLO11 detection export with one box and class score output.
- Import a custom RF-DETR export with its own class count. Name the slots in a
  `labels.json` file beside the model.
- Compare the shipped detector with a project detector on a recorded session.
- Import an ONNX crop classifier. The active classifier scores live proposals
  instead of the fingerprint pool.
- Labels for a classifier come from a JSON array beside the model, or from the
  project classes in id order.

## Label and data

- Export the project dataset as YOLO images, labels, class names, `data.yaml`
  and a manifest.
- The export also writes one crop folder per class for classifier work.
- Import a Roboflow dataset from a folder that holds `data.yaml`.
- The review queue accepts, rejects, skips and removes harvested candidates.
- The matcher cap now keeps a spread of examples instead of the newest rows.
  This lowers duplicate examples and makes a capped pool more representative.

## Interface

- Label and Capture lab show a real empty state when no frame exists.
- Project name fields have visible labels.
- Session and detector deletion uses an inline confirmation, not a native dialog.
- Review and Label loading buttons show a spinner and set `aria-busy`.
- Evaluate uses a check icon for a marked class instead of a text glyph.
- Detectors empty states name the next action.
- Settings reads the installed app version instead of a fixed fallback.

## Windows

The release includes the Windows installer and signed update artifacts.
Existing installs can check Settings for the update after the release is
published.
