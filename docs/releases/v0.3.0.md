# iRecon 0.3.0

This release finishes the first full interface pass and completes the labeling loop.

## Label

- Work through several frames in one session with a frame strip, a Next unlabeled action, and a saved-example count on every frame.
- Draw several boxes on one frame, assign each box as a positive or negative, and save them together.
- The frame viewer now matches the source aspect ratio instead of cropping the image. Scroll to zoom, Shift-drag to pan, and use fullscreen to fit the available window.
- Grab frame has a customizable shortcut. Click the shortcut control, press a key, and that key is saved locally. Set it to None to disable the shortcut.
- The frame viewer help now states that iRecon hides its own windows, but other windows stay in the shot.

## Capture

- Grab frame saves the full primary display at its native resolution. The Label viewer uses a smaller preview, but crops are taken from the full-size frame.
- The capture guard now checks the app window area instead of the whole screen, so unrelated desktop motion cannot let a stale frame through.
- The guard refuses a saved frame when the app window area did not change, instead of accepting a frame that may still contain iRecon.

## Interface

- Navigation is grouped into Set up, Teach, and Run. The sidebar can be closed and reopened, with Control+B as a shortcut.
- The header shows a compact live indicator when capture is running and the sidebar is closed.
- Start here keeps the first-run sequence and drops the duplicated navigation.
- Capture lab uses one run panel with the primary metrics, with secondary numbers in a compact status line.
- Detectors use consistent form controls and a clearer empty state.
- Library, Sources, Review, Sessions, and Evaluate have cleaner spacing, visible labels, and fewer duplicated empty-state messages.
- Scrollbars follow the light and dark theme instead of using the default white track.
- Settings is more compact, and frame example counts now come from the database.

## Windows

The release includes the Windows installer and update artifacts. Existing installs can check Settings for the update after the release is published.
